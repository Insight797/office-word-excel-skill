# 办公室 Word/Excel 自动化

目标用户:老师、行政、辅导员这类不写代码的人。他们丢来一堆文件 + 一句"帮我把…整理好"。交付标准:**结果文件打开就能用,原件毫发无损,干了什么一目了然**。

**先确认运行平台**(sys.platform / uname),文件转换工具按平台分流,见 §4。Windows 上注意 §5 的编码与路径坑。

## 0. 黄金工作流(每个任务必走)

1. **先看样本**:先读 1~2 个样例文件,向用户复述结构和你的理解(表头几行?有无合并单元格?模板待填处在哪?)。看不清就问,别猜。
2. **规则一次问清**:填哪些列/哪些人、空值与重复怎么办、格式要求(要不要精确到市、编不编号、文件命名规则、排名并列怎么算)。
3. **试跑 3~5 条**:给用户过目,确认口径后再全量。批量任务永远不要一把梭。
4. **不碰原件**:输出写新文件或新文件夹;`~$` 开头的 Office 锁文件一律跳过。
5. **交付三件套**:结果文件 + 校验报告(成功/跳过/失败各多少、每列填写率)+ 失败/缺失清单写成 txt 放结果旁边——不要只在对话里口头汇报。

## 1. Excel 套路

写入用 openpyxl,统计排名用 pandas(两库跨平台通用)。

- **只填空缺不覆盖**:写前检查 cell 为空。多来源往同一张表灌时按顺序来,已有数据一律跳过。
- **合并单元格表头**(学校表格标配):值只在左上格,写其他格会报错;多行合并表头要把几行都读进来定位真实列号,别假设第 1 行是表头。
- **学号/身份证/电话一律按文本处理**:防前导零丢失和科学计数法;比较前 `str().strip()` 归一——Excel 里数字与文本混存是匹配失败的头号原因。
- **格式保真**:openpyxl 重写会丢图表、部分条件格式和复杂样式,原表有这些时先提醒用户(可建议改用 Excel 原生功能如数据分列/Power Query 完成)。
- **CSV 编码**:老系统导出多为 GBK/GB18030,`encoding='gbk'` 起步,兜底 `utf-8-sig`。
- **两表合并**:双主键(如 姓名+电话后四位 / 姓名+学号),只按姓名必踩重名坑;对齐后按主键回填。
- **去重**:按主键保留首条,删行后核对总数。
- **抽子集**:按名单筛行 → 新 xlsx,**表头原样带上**。
- **超链接**:重排/复制行会丢超链属性,丢了就按相对路径批量重插。
- **XML 安全**:openpyxl 保存报 XML 错 = 文本含控制字符,统一过滤:

```python
def clean_for_excel(s):
    return ''.join(c for c in str(s) if c in '\n\t' or ord(c) >= 32)
```

## 2. Word 套路

python-docx 为主(跨平台)。

- **读**:段落 + 表格 cell 都要读,申请表/登记表的信息大量藏在表格里。
- **模板套打**(证书/通知/合同/奖状/信封):占位符(`«姓名»`、`${name}`)直接替换;没有占位符就在对应表格 cell/段落里定位关键字。**替换必须落到 run 上**,直接改 `para.text` 会把整段格式清光。
- **批量生成**:每条记录出一个文档,命名规则(`1_张三` / `学号_姓名`)先和用户确认;上百份时用 tqdm 打进度。
- **中文字体**:只设 `run.font.name` 不生效,必须同时设东亚字体:
  `run._element.rPr.rFonts.set(qn('w:eastAsia'), '宋体')`
- **正式文档排版基线**:标题黑体、正文宋体小四、行距 1.5、表格全边框;合同/公文类先问单位有无模板,有模板一切以模板为准。
- **生成后回读验证**:重新打开生成的文件,数一遍份数、抽查内容,再交付。

## 3. Word↔Excel 交叉(办公室最高频)

| 任务 | 套路 |
|------|------|
| 按名单挑文件/归档 | 姓名匹配文件名 → 内容验证(电话等)→ 拷入结果文件夹 → 报告缺失名单 |
| 批量重命名 | 按 Excel 行序生成 `1_张三 2_李四` 前缀;改过一轮再换正式序号时先备份 |
| 文档信息汇总 | §4 兜底链读取 → 提取字段 → 双主键对位 → 只填空缺 |
| 名单→批量生成 Word | 证书、奖状、通知、座位表:模板套打 + 确认命名规则 |
| 成绩单统计 | pandas 求和/平均/排名;**先确认"排名并列怎么算、缺考算不算"**再动手 |
| 附件图片提取 | docx 图在 `word/media/`;doc/扫描 pdf 用 fitz(`page.get_images` + `extract_image`);**提取后逐个验证可打开**,doc 转出的图常有损坏 |
| 逻辑校验 | 交叉检查"专业 vs 单位""地址 vs 省份列"等,输出问题清单;小范围校验直接读文件比写脚本快 |

## 4. 文件读取兜底链(按平台分流)

通用规则:批量任务先抽样读通再写全量循环;单文件 try/except 隔离;跳过 `~$` 锁文件;PDF 提取文字 < 50 字符视为扫描件 → OCR;PDF 值常与栏目名粘连,正则兼容换行版和空格版排版。

### `.doc` 转换(平台差异最大)

| 平台 | 首选 | 备选 |
|------|------|------|
| macOS | `textutil -convert txt -stdout <file>` | — |
| Windows | LibreOffice:`soffice --headless --convert-to txt:Text <file>` | 装了 Office 则用 Word COM(`win32com.client`,需 pywin32)另存为 docx/txt |
| 任意 | 损坏文件 → `olefile` 读 WordDocument 流(UTF-16-LE) | — |

Windows 上先探测工具是否可用(`soffice` 不在 PATH 就试 COM,都没有则请用户安装 LibreOffice 或手动另存),不要假设装了 Office。

### 其余格式(跨平台一致)

| 格式 | 首选 | 兜底 |
|------|------|------|
| `.docx` | python-docx(段落+表格都读) | 走上面的 doc 转换链 |
| `.xls` | pandas + xlrd | 提示用户用 Excel 另存为 xlsx 再来 |
| `.pdf` | pdfplumber / `pdftotext -layout`(poppler) | pdf2image + OCR |

### OCR

EasyOCR 跨平台;`torch.device` 按可用性选:macOS 用 MPS,Windows 有 NVIDIA 用 CUDA,否则 CPU(慢,提前告知用户耗时)。

## 5. 中文办公环境特有坑

### Windows 专属

- **控制台是 GBK**:子进程输出、print 中文易 UnicodeEncodeError。脚本开头 `sys.stdout.reconfigure(encoding='utf-8')`,或让用户设 `PYTHONUTF8=1`、`chcp 65001`。
- **中文路径 + subprocess**:传参用字符串列表(`subprocess.run([...])`),不要 `shell=True` 拼命令;路径用 `pathlib.Path` 处理,别手拼反斜杠。
- **Office/WPS 装哪家不确定**:COM 自动化(`win32com`)对真 Office 最稳;WPS 兼容模式有时可用,失败就退回 LibreOffice 路线。

### 通用

- **WPS 保存的文件**:偶发 openpyxl 读写异常,让用户提供 Excel 另存版,或读入后全量转存一份。
- **全角/半角与内部空格**:栏目名常写作"姓 名""性　别",匹配用正则 `姓\s*名`。
- **复选框**:勾选符号有 ☑ ✅ ✔ √ Ρ ▇ 等变体,反选 □ 也要识别;模板提示语("请勿修改此行""省/自治区/直辖市")当噪声过滤。
- **编号格式忠实原文**:多选条目保留原大小写编号,别擅自统一改数字;多项才编序号,单项不编号。改需求回头修历史数据时,先备份再动。
- **地址/省份**:通讯地址优先、户籍所在地兜底,精确到市("山东省济南市");维护一份省市全称映射,把"黑龙江""内蒙古"等简称补全。
- **推断字段要留痕**:无明确值时三级推断(原文关键词 → 上下文类型 → 间接线索),并在报告里标注哪些是推断出来的。

## 6. 校验与交付纪律

1. **改完必验**:全量跑完抽样回读与原件对照,统计每列/每人填写率。
2. **失败落地**:提取失败、信息缺失的名单写入 `缺失清单.txt` 之类文件,放结果旁边。
3. **发现历史错误**(重名错配、张冠李戴):先报告,经确认再修,修后重验相关范围全部行。
4. 一次性脚本也**迭代版本**(v2/v3…),文件头注释写清本版改动;同项目复用同一脚本,不要每次重写。
